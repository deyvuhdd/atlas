Atlas privacy policy

Last updated: November 20, 2026

Atlas is a private app used only by its owner. It has no other users.

What Atlas accesses

When the owner signs in with Google, Atlas gets access to that Gmail account (the https://mail.google.com/ permission) so it can show the owner's mail, help sort it, mark messages read when the owner opens them, and send replies only when the owner taps Send.

Where data is kept

Mail and sign-in tokens are stored encrypted on a server the owner controls. Nothing is stored by any third party on Atlas's behalf.

Sharing

Atlas does not sell, share, or transfer Google user data to anyone. It is not used for advertising. Data is processed by an AI model only to summarize and sort the owner's own mail for the owner.

Atlas's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove an account in Atlas at any time, which deletes Atlas's copy of that mailbox, and can revoke access at myaccount.google.com/permissions.
